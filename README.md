## About the course files

I preserved each course inside its own folder so the exercises do not overwrite one another. Course-specific files such as `.github` workflows and `.devcontainer` configuration remain inside their respective course directories.

Because GitHub only runs workflows from the repository root, the nested course workflows are kept here as learning artifacts and do not run automatically in this consolidated repository.

The original GitHub Skills repositories are archived copies of the standalone exercises. This repository is my main public showcase, while the original repositories remain linked above for reference.
