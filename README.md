## Notes on course automation

Course-specific automation (for example `.github` workflows and `.devcontainer` configuration) is preserved inside each course directory as learning artifacts.

Because GitHub only executes workflows from the repository root (`/.github/workflows`), these nested course workflows are archived and do not run automatically in this combined repository.

## Source of truth

The original course repositories remain the authoritative source for rerunning interactive GitHub Skills courses and automated checks.

This archive preserves learning artifacts and progress; it does not replace the original GitHub Skills course experience.
